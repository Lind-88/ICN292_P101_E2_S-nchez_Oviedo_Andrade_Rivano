# Cambios de E1 a E2

La Entrega 2 mantiene a Almacén La Maestra como caso de estudio y concreta el diseño de E1 en un prototipo de captura, una base de datos, consultas y flujos exportables. 

| Componente          | En E1                                                                                          | En E2                                                                                                                                                                              |
| ------------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Captura             | La arquitectura propuesta consideraba una interfaz en Python con Streamlit.                    | El prototipo usa Python con Tkinter. Incluye formularios de ventas, compras, gastos, pan, proveedores y categorías, con validación de campos e inserción en MySQL.                 |
| Proceso To-Be       | El carril SIG concentraba las validaciones, recordatorios y recomendación de compra de pan.    | El BPMN muestra la interacción entre captura, persistencia y n8n, además de la revisión de avisos y las decisiones del encargado.                                                  |
| Datos               | El informe E1 definió un modelo preliminar de seis entidades.                                  | El esquema MySQL define las seis tablas, sus claves primarias y dos claves foráneas. La semilla de demostración cubre 14 fechas de cierre y control de pan.                        |
| Indicadores         | Power BI figuraba en la arquitectura tentativa.                                                | La evidencia de E2 son cinco consultas SQL interpretadas, verificadas en MySQL 8.0.46.                                                                                             |
| Avisos de registros | El diseño incluía revisiones separadas para ingresos y egresos.                                | El Nivel 1 reúne el cierre, el control de pan y los conteos de facturas y gastos en un resumen diario a las 22:20.                                                                 |
| Reposición de pan   | Se planteaba consultar el historial, estimar consumo y enviar una recomendación para revisión. | El Nivel 2 define horarios, reglas de cálculo y una marca por fecha para controlar avisos duplicados. Con historial insuficiente, pide al encargado definir la compra manualmente. |
